# CodeAlpha C++ Programming Internship

## Task 1: University GPA & CGPA Calculator (CGPA_CALCULATOR.CPP)
A C++ console program that calculates semester GPA and overall CGPA across multiple courses and credit hours.

## Task 2: Secure User Authentication System (LOGIN SYSTEM.CPP)
A C++ login and registration system built with OpenSSL (libcrypto) featuring:
- 16-byte random salt generation (RAND_bytes)
- PBKDF2-HMAC-SHA256 password hashing with 600,000 iterations
- Constant-time hash verification (CRYPTO_memcmp)
- 3-attempt login lockout protection (MAX_LOGIN_ATTEMPTS = 3)
- Persistent user storage in users.txt
## Task 3: Sudoku Solver (SUDOKU_SOLVER.CPP)
A 9x9 Sudoku puzzle solver in C++ using recursive backtracking and row/column/3x3 subgrid validation.
